## 🚀 Getting Started

To explore the assignments locally:

1.  Clone this repository:

    ``` bash
    git clone https://github.com/Rushikesh-Hadawale/Full-Stack-Assignment.git
    ```

2.  Open the repository folder:

    ``` bash
    cd Full-Stack-Assignment
    ```

3.  Open the folder of the assignment you want to explore.

4.  Follow any instructions or setup steps provided inside that
    assignment's folder.
